서재를 드라이브에 연결합니다

두 칸은 이미 채워져 있습니다. 아래 버튼만 누르시면 됩니다. 한 번 연결하면 맥북과 폴드에서 같은 책, 같은 위치로 이어집니다.

하위 폴더까지 전부 찾습니다. EPUB과 PDF를 모두 읽습니다.
처음 설정하는 법
  1. console.cloud.google.com → 새 프로젝트를 만듭니다.
  2. API 및 서비스 → 라이브러리 → "Google Drive API" → 사용.
  3. OAuth 동의 화면 → 외부 → 앱 이름과 본인 이메일 입력.
  4. 테스트 사용자에 본인 Gmail을 추가합니다. 빠지면 로그인이 막힙니다.
  5. 사용자 인증 정보 → OAuth 클라이언트 ID → 웹 애플리케이션.
  6. 승인된 자바스크립트 원본에 도메인까지만 넣습니다: https://younghki92-oss.github.io
  7. 첫 로그인 때 뜨는 "확인하지 않은 앱" 경고는 고급 → 이동으로 넘어갑니다.
