서재를 드라이브에 연결합니다

한 번만 설정하면 맥북과 폴드에서 같은 책, 같은 위치로 이어집니다.

구글 클라우드 콘솔에서 발급받은 값입니다. 아래 "처음 설정하는 법"에 순서가 있습니다.
드라이브에서 폴더를 열었을 때 주소의 folders/ 뒤에 붙는 긴 글자입니다. 하위 폴더까지 전부 찾습니다.
처음 설정하는 법
  1. console.cloud.google.com 접속 → 상단에서 새 프로젝트를 만듭니다. 이름은 아무거나("서재") 괜찮습니다.
  2. 왼쪽 메뉴 API 및 서비스 → 라이브러리 → "Google Drive API" 검색 → 사용을 누릅니다.
  3. OAuth 동의 화면 → 사용자 유형 외부 → 앱 이름과 본인 이메일만 채우고 저장합니다.
  4. 같은 화면의 테스트 사용자에 본인 Gmail 주소를 추가합니다. 이게 빠지면 로그인이 막힙니다.
  5. 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID → 유형 웹 애플리케이션.
  6. 승인된 자바스크립트 원본에 이 앱의 주소를 넣습니다. 끝의 저장소 이름은 빼고 도메인까지만 넣어야 합니다. 예: https://younghki92-oss.github.io
  7. 만들면 나오는 클라이언트 ID를 복사해 위 칸에 붙여넣습니다.
  8. 처음 로그인할 때 "Google에서 확인하지 않은 앱" 경고가 뜹니다. 고급 → 이동을 누르면 됩니다. 본인만 쓰는 앱이라 정상입니다.
